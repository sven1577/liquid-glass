## 2024-11-04 - Accessible Custom Toggle Focus Indicators
**Learning:** In highly customized, minimalist web interfaces (such as glassmorphic cards), semantic input elements like checkboxes are often visually hidden using `opacity: 0` or `pointer-events: none` inside a parent `<label>` to style custom tracks and thumbs. However, this completely obscures browser-default focus indicators, rendering the toggle inaccessible to keyboard navigation and screen-reader users who tab through form fields.
**Action:** Always map focus states of visually-hidden inputs to their custom visual container using adjacent sibling selectors (e.g., `input:focus-visible + .switch-track`). Use `box-shadow` or standard `outline` with appropriate spacing to match the design system aesthetics, ensuring keyboard-navigating users always have clear visual feedback on focus.
