## 2026-11-05 - Draggable Physics Card Keyboard Navigation & Focus Accessibility
**Learning:** Interactive components controlled by pointer drag and spring physics (such as floating glassmorphic cards) are completely inaccessible to keyboard-only and screen reader users unless explicit keyboard handlers map arrow keys to coordinate targets. Furthermore, when handling keyboard navigation on container elements, checking `e.target !== container` is critical so that keystrokes originating inside nested input fields do not trigger unexpected card translations.
**Action:** Provide `tabindex="0"`, descriptive accessibility attributes (`aria-label`, `aria-description`), and keyboard event handlers on draggable physics containers that translate physics targets directly, guarding against propagation from child controls.
