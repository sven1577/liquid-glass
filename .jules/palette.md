## 2025-05-18 - Visible Focus States and Form Feedback on Glassmorphic Cards
**Learning:** Dark/glassmorphic UI backgrounds obscure standard browser focus rings and lack native submission visual cues on demo CTA cards. Using `:focus-visible` with high-contrast outlines and immediate inline state transitions provides clear keyboard navigation and submission feedback without disrupting glass aesthetics.
**Action:** Always include `:focus-visible` styling for customized interactive elements in glass UI cards, and provide immediate visual state changes upon async/demo form submission.
