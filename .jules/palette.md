## 2024-11-23 - Dynamic Canvas Re-measurement in Glassmorphic Cards
**Learning:** In glassmorphic interfaces that use pre-rendered canvas-based displacement maps (like Liquid Glass), any dynamic DOM updates that change the size of the glass component (such as transitioning from a signup form to a success message) will result in broken, misaligned, or cropped refraction effects. This happens because the displacement map coordinates become stale and no longer align with the updated layout boundaries.
**Action:** When modifying the internal DOM of a glassmorphic container, always trigger a sequential re-measurement (`measure()`) and refresh of the SVG filter or canvas-based displacement map (`refresh()`) immediately following the layout transition to maintain visual correctness.
