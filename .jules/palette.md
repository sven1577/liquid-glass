## 2025-02-18 - Keyboard Accessible Drag & Drop Physics Widgets and Hidden Toggle Inputs
**Learning:** For floating components mapped to physics simulations (e.g., spring-based transition coords tx/ty), simple pointer event capture excludes keyboard-only users. Similarly, hiding standard checkboxes with opacity: 0 to create custom CSS toggle indicators completely breaks visual focus cues.
**Action:** To make physics-based elements accessible, map keyboard arrows directly to the target physics coordinates (tx/ty) rather than modifying styling directly, allowing the spring-physics animation loop to gracefully transition the element. For hidden toggles, use the adjacent sibling selector linked with `:focus-visible` (e.g., `input:focus-visible + .switch-track`) to display high-contrast, beautiful focus rings that match the design system.
