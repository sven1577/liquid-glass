## 2025-08-16 - Offscreen Canvas Reuse and LRU Data URI Caching for SVG Displacement Maps
**Learning:** In SVG displacement map liquid glass effects, dynamic `<canvas>` allocations on every `refresh()` or resize trigger significant garbage collection pressure. Additionally, `canvas.toDataURL()` calls are CPU-heavy operations. Reusing a single module-scoped offscreen canvas context combined with a Map-based bounded LRU cache (indexed by element dimensions, corner radius, border inset, and map blur) avoids duplicate rasterization and base64 encoding while preventing memory leaks.
**Action:** When working with dynamically generated canvas textures or SVG filter map sources, implement shared canvas context reuse and bounded LRU caching for generated Data URIs, and skip DOM attribute updates when dimensions are unchanged.
